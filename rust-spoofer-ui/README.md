# Rust Spoofer UI

Нативное десктопное пользовательское приложение на Python для демонстрации интерфейса.

## Запуск

Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## Назначение

Проект содержит только демонстрационный интерфейс. Кнопка не изменяет HWID и не запускает внешнее ядро.
